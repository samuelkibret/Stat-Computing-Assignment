# Git Skills Test Assignment

This repository demonstrates basic Git and GitHub workflows for a skills test assignment.

## Project Objectives
* Create a local Git repository and perform commits.
* Connect local repository to a remote GitHub repository.
* Practice core workflow: add, commit, and push.
* Create a formatted README file using Markdown.
* Share work publicly on GitHub.

## Repository Contents
* `README.md`: Project description and documentation.
* `NMIS.CSV`: Market information data.

## Setup and Usage
1. Clone the repository:
   ```bash
   git clone https://github.com/samuelkibret/Stat-Computing-Assignment.git
   ```
2. Navigate to the directory:
   ```bash
   cd Stat-Computing-Assignment
   ```
3. Run the script:
   ```bash
   python sample_data.py
   ```

## Git Workflow
* Check status: `git status`
* Stage changes: `git add .`
* Commit changes: `git commit -m "commit message"`
* Push to GitHub: `git push origin main`
